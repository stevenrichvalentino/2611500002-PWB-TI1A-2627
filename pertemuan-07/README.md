
# P7 Pemrosesan Formulir dengan PHP, Validasi Sisi Peladen, dan PRG

## Deskripsi Proyek
Melanjutkan pengembangan artefak P6 untuk memproses masukan formulir di sisi peladen menggunakan metode GET dan POST, validasi server-side, pengamanan keluaran HTML, session, dan pola Post-Redirect-Get (PRG).

- Berkas disalin dari pertemuan-06: index.php, style.css, script.js, dan img/foto-profil.jpg.
- Pengujian awal: Mengakses alamat http://localhost/.../pertemuan-07/ dan memastikan tampilan sama dengan P6.
